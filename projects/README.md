# Projects

One folder per machine-coding project. Each project goes with one or more lessons of the course and is written in every language the course teaches.

No projects yet. They are added as the course's lessons are written.

## Inside a project

```
projects/<project>/
├── README.md          the task, how to run it, hints, then the solution links
├── project.json       title, lessons, test names per round
├── demo-output.txt    what the finished demo prints
└── <language>/        one folder per language: cpp, java, javascript, python
    ├── README.md      the commands for this language only
    ├── starter/       main branch: the code to finish, plus the tests
    └── solution/      solutions branch only
```

Open your language's `starter` folder and follow the README. The tests tell you when you are done.
