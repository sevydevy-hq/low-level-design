# Contributing

Thanks for helping. This repo is the code for a course, so every file has to match what a lesson says. That shapes what we can accept.

## Report a problem

- **A bug in the code** (a test that is wrong, a command that fails, a crash): open an issue. Say which project or example, which language, the exact command you ran and what it printed.
- **A problem in a lesson** (text, diagram, check question): use the Report button on the lesson page on sevydevy.com.
- **A security problem:** don't open an issue. Follow the security policy of the SevyDevy organisation.

## Pull requests

We accept pull requests for **fixes only**: a wrong test, a bug in a solution, a command that fails on some system, a typo in a README.

We don't accept new projects, new languages or redesigns, because each one has to be written into a lesson first.

Before you open one:

1. Keep it to one fix.
2. Run the project's tests in the language you changed, on the starter (main branch) or the solution (solutions branch).
3. If you change a starter or a test, say so: the same change is needed on the `solutions` branch.

Every pull request is checked automatically on Linux, Windows and macOS, then reviewed before it is merged.
