# Examples

The full, runnable file behind each code example in the lessons. A lesson shows 30 lines at most; the whole file is here, in every language, with the output it really prints.

No examples yet. They are added as the course's lessons are written.

## Inside an example

```
examples/<lesson>/<example>/
├── README.md              what the example shows and how to run it
├── example.json           lessons, extra source files, "sameOutput"
├── expected-output.txt    what it prints, when every language prints the same
└── <language>/            the files, plus expected-output.txt if this language prints something different
```

Examples have no starter and no hidden solution: the lesson already shows the code. The one exception is the reference answer to a lesson's "Build it yourself" task, which the lesson keeps in a fold.
